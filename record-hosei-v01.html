Settings
SAMPLE RATE
Set the Scarlett to the same rate in Audio MIDI Setup. A mismatch is resampled by macOS. The rate cannot be changed while recording or playing.
Test signals play at −20 dBFS. Use them, or the Mac's built-in microphone and speakers, to try the app without the Scarlett. Keep the volume low when using speakers and a microphone together.
RECORDINGS FOLDER
—
Choose the "Records" folder. Each album is a sub-folder "[Artist] - [Album]" containing the WAV takes, cover.jpg and album.json. The library is rebuilt from album.json.
TRACK DETECTION (SILENCE BETWEEN TRACKS)
The noise floor is estimated from the surface noise at the start and end of the side. A quiet stretch longer than the minimum gap becomes a track boundary.

CORRECTION DATA
Export writes all cartridges, their L/R and tone data, emulation pairs, interface calibration and latency to one JSON file. Import replaces the current data. Delete removes all measured data but keeps the cartridge names.
